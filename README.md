# Incident-Client-Script-UI-Policy
Configure an Incident Client Script and UI Policy to automate field validation and control field visibility, mandatory status, and behavior based on incident conditions.
## Project Overview

**Incident Client Script & UI Policy** is a ServiceNow project designed to improve the Incident Management process by automating form behavior and validation. The project uses **Client Scripts** and **UI Policies** to dynamically control incident fields based on specific conditions.

### Key Objectives

* Automate Incident form behavior.
* Make required fields mandatory based on conditions.
* Validate incident information before submission.
* Control field visibility, read-only status, and mandatory status.
* Reduce manual errors and improve data accuracy.
* Provide a better user experience for Incident Management.

### Technologies Used

* **ServiceNow**
* **Incident Management**
* **Client Script**
* **UI Policy**
* **JavaScript**

### Expected Outcome

The implementation ensures that Incident records contain the necessary information before submission while dynamically adapting the form according to the incident's state and conditions.
